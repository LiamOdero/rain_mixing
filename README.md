# rain_mixing
![Preview of the GUI](/src/assets/readme/preview.PNG)

A music player that seamlessly mixes rain SFX with selected music 


# Usage
- Use the add folder button to give the program a folder containing music files you wish to play
- Program will automatically detect supported files in said folder and any subdirectory
- Supported extensions are currently .mp3 and .wav
- Right click any individual track in the file view to play it
- Right click any folder in the file view to play through files in the folder
